# Support

## Maintainer

[Thiago Salles](mailto:thiagosalles@microsoft.com) maintains Kognition and manages
community interactions, pull request review and merging, issue feedback, and
release coordination. Use GitHub Issues for ordinary project questions.
Security reports must follow [SECURITY.md](SECURITY.md) rather than email to the
maintainer or public issues.

## Issues and Questions

Use this repository's GitHub Issues for reproducible bugs, feature requests and
questions about Kognition. Search existing issues before opening a new one.
Include the version, operating system, deployment mode and a minimal
reproduction. Remove credentials, personal data and confidential deployment
details from logs and manifests before sharing them.

Report security vulnerabilities privately according to [SECURITY.md](SECURITY.md),
not through public issues.

## Microsoft Support Policy

Support for Kognition is limited to the resources listed above. This repository
does not provide a Microsoft Customer Service and Support commitment or a
response-time guarantee.
